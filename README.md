# HVE Core for PMs/TPMs: Product Ambiguity to Governed Backlog

A self-paced workshop focused on the **Design Thinking lifecycle**: experience the problem domain, start from an ambiguous idea, learn through user evidence and prototypes, then carry the result into a governed BRD, PRD, and Epic/Feature planning baseline.

## What you'll learn
- Recognize a product problem before prematurely writing requirements.
- Use HVE Core Design Thinking Methods 1–6 to reduce ambiguity.
- Preserve evidence confidence, contradictions, assumptions, and open questions.
- Move from research evidence to a coherent concept and prototype-learning loop.
- Hand Design Thinking evidence safely into BRD and PRD creation.
- Govern unresolved dependencies as explicit gates.
- Create a traceable Epic/Feature backlog without entering engineering execution.

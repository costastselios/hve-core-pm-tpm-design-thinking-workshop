# Canonical Concept Snapshot

## Concept
**Adaptive Maintenance Portfolio + Factual Portfolio Story + Progressive Valuation Transparency**

## User promise
Maintain one trustworthy investment record across platforms and understand factual portfolio value/history without real-time trading behavior or speculative forecasts.

## Journey
1. Establish holdings by import, with guided manual fallback.
2. Orient to consolidated current value and factual history.
3. Inspect holding detail and provenance.
4. Record or import supported activity.
5. Review uncertain imported activity before commitment.
6. Understand an evidence conflict before recovery.
7. Preserve historical uncertainty when only today's state is verified.

## Action hierarchy
**Portfolio:** Add holding, Import, history/orientation, trust/freshness.  
**Holding:** inspect, add transaction, transaction history, provenance, resolve conflict.

## Trust model
Calm portfolio orientation with freshness/provenance on demand. Incomplete history stays qualified.

## D/F/V assumptions
**D/F/V = Desirability / Feasibility / Viability.**
- Desirability: consolidated factual history and visible uncertainty are useful.
- Feasibility: asset/price/FX/identifier coverage and reviewed import normalization can be achieved.
- Viability: data licensing/provider constraints can support an eventual pilot.

## Open decisions
Provider coverage, valuation cutoffs, fees, duplicate logic, corporate actions, cost basis, financial methodology, licensing, unsupported assets.

## Validation boundary
Evidence-informed, not validated. Method 6 is for learning, not proof.

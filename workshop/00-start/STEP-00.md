# Step 0 — Start from an ambiguous product idea

**Agent:** None

## Your role in this step
Recognize ambiguity rather than prematurely creating requirements.

## Do
1. [Open the ambiguous product idea](ambiguous-product-idea.md).
2. Read it once without rewriting it into requirements.
3. Open VS Code Copilot Chat.

## What good looks like
You can identify problem clues, solution assumptions, and unresolved details in the starting input.

## Stop
You understand the starting document is an early hypothesis, not validated requirements.

## Recover if needed
If you find yourself turning the idea into requirements, pause and reread the document as hypotheses.

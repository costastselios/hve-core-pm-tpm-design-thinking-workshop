# Iteration 1 — Supplied Prior Participant-Test Evidence

## Observed / reported behavior
- Portfolio → holding → transaction flow was understood.
- Portfolio Import was discoverable.
- Detailed valuation provenance was useful once opened.
- Import/recovery terminology was confusing.
- Recovery was completed mechanically, but the participant could not explain whether it changed today's holding, historical activity, or both.

## Interpretation
The recovery mental model failed comprehension. It mixed current correctness with historical repair.

## Open questions
- Can current impact and historical impact be explained separately?
- Can today's holding be verified without implying history is repaired?
- Can the user predict consequences before confirmation?

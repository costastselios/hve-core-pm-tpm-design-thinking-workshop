# Prototype Test Script

## Task A — Establish and orient
- Use the prototype's **Use workshop statement** action to establish holdings. The statement is simulated inside the HTML; no separate filesystem file is required.
- Create the portfolio.
- Review the portfolio overview and explain current standing and historical direction.
- Open a holding and inspect valuation provenance.

## Task B — Maintain and recover
- Add a supported transaction to the holding.
- Use the prototype's **Use workshop activity file** action. The activity file is simulated inside the HTML; no separate filesystem file is required.
- Return to the holding and open the mismatch.
- Before choosing a recovery action, write down what each option appears to change.

## Evidence discipline
Your self-test is **not user research**. Keep separate:
- your observation;
- your interpretation;
- supplied prior participant evidence;
- open validation question.

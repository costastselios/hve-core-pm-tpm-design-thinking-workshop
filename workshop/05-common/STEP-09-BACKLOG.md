# Step 9 — Epic / Feature Backlog

**Agent:** Product Manager Advisor

## Your role in this step
**Your job:** judge outcome/capability boundaries and gate status. **HVE’s job:** decompose the approved PRD. **Do not worry about:** Stories, Tasks, estimates, sprint sequencing or implementation.

## Do
1. Select **Product Manager Advisor**.
2. Paste:
```text
Using the approved PRD as source of truth, create the initial backlog proposal. Stop at Epic and Feature. Preserve PRD traceability. Do not turn deferred scope into backlog items. Capabilities blocked by unresolved dependencies may appear only as conditional candidates with explicit gates, not committed release Features. Do not create Stories, Tasks, architecture, estimates, sprint sequencing, RPI plans or code. No financial amounts.
```
3. Review with the [Artifact Checklist](../../docs/ARTIFACT-CHECKLIST.md) and [Feature vs Task example](../../docs/WORKED-EXAMPLES.md).

## What good looks like
Epics are outcomes, Features are capabilities, and gated capabilities are visibly conditional.

## Stop
A complete Epic/Feature proposal exists with PRD traceability and explicit gate status.

## Recover if needed
```text
Stop decomposition. Remove Story/Task-level items. Keep only outcome-oriented Epics and capability-oriented Features with PRD traceability and gate status.
```

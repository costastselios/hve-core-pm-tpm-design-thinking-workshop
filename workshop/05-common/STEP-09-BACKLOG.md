# Step 9 — Backlog

**Agent:** Product Manager Advisor

## Your role in this step
Judge outcome/capability boundaries and gate status.

## Do
Before leaving PRD Builder, confirm the **approved PRD planning baseline** from Step 8 is saved as a file. Then select **Product Manager Advisor** and attach that file using your VS Code Copilot file-context mechanism. Make sure the attached baseline includes its inherited exclusions and open gates. Don't rely on the previous agent's chat context.

Ask for Epics/Features only, preserve PRD traceability back to that approved baseline, exclude deferred scope, keep gated capabilities conditional, and create no Stories/Tasks/architecture/estimates/RPI/code. Review [worked examples](../../docs/WORKED-EXAMPLES.md).

## What good looks like
Epics are outcomes; Features capabilities; gates visible.

## Stop
Complete Epic/Feature proposal.

## Recover if needed
If agent decomposes too deeply, stop and roll back Story/Task-level items.

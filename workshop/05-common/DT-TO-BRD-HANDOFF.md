# Design Thinking → BRD Handoff

## Minimum evidence set
- [ ] M1 scope/problem and open questions
- [ ] M2 research assessment/confidence and participant differences
- [ ] M3 synthesis/tensions/opportunity
- [ ] M4 divergent directions/convergence basis
- [ ] M5 user concept
- [ ] M6 prototype learning and validation gap
- [ ] Canonical concept snapshot
- [ ] Open assumptions/questions preserved

## Continuity cases
**A — discoverable:** verify BRD Builder names the evidence baseline.  
**B — files not discovered:** explicitly reference/attach the relevant files.  
**C — conversation-only:** ask DT Coach to create a concise DT→BRD handoff artifact before switching.

## Fallback prompt
```text
I completed HVE Core Design Thinking Methods 1–6.
Use the DT-to-BRD handoff and referenced evidence as the baseline.
First state which evidence you can access.
If anything is unavailable, identify it before drafting an affected requirement.
Do not reconstruct missing research or treat unavailable evidence as fact.
Preserve confidence, open questions, and the Iteration 2 validation gap.
```

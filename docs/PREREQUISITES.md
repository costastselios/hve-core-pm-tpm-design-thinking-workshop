# Prerequisites and Setup Check

## Required environment
- VS Code with GitHub Copilot Chat.
- Your organization's supported HVE Core setup.
- Agents: **DT Coach**, **BRD Builder**, **PRD Builder**, **Product Manager Advisor**.

## Readiness
- [ ] DT Coach visible
- [ ] BRD Builder visible
- [ ] PRD Builder visible
- [ ] Product Manager Advisor visible

## Providing files to Copilot Chat
Use the file-context mechanism available in your VS Code Copilot Chat, such as **Add Context**, the workspace file picker/reference syntax, or drag-and-drop when supported. Verify the file appears in chat context before sending the prompt.

## Missing agent?
Stop rather than substituting another agent. Use your organization's HVE setup instructions, restore the missing agent, then repeat the check. This package does not invent a required HVE version or installation procedure.

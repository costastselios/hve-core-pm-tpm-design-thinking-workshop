# Prerequisites
- VS Code with GitHub Copilot Chat.
- Your organization's supported HVE Core setup.
- Agents visible: **DT Coach**, **BRD Builder**, **PRD Builder**, **Product Manager Advisor**.

## Readiness
- [ ] DT Coach
- [ ] BRD Builder
- [ ] PRD Builder
- [ ] Product Manager Advisor

## Providing files to Copilot
Use the file-context mechanism available in your VS Code Copilot Chat: for example **Add Context**, the workspace file picker/reference syntax, or drag-and-drop when supported. Verify the intended file appears in chat context before sending the prompt.

If an agent is missing, stop rather than substituting another agent. Use your organization's HVE setup process, then repeat this check.

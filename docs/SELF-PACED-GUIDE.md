## Natural break points
Pause safely after Steps **3, 6, or 8**. These are planning suggestions, not time targets.

## Resume after a break
1. Return to the first unchecked step.
2. Reopen the latest artifact/handoff from the prior step.
3. In a new chat, select the required agent and provide the latest handoff/artifacts.
4. Paste:
```text
I am resuming this self-paced HVE workshop at the referenced Step.
Use the supplied artifact(s) as the current baseline.
First summarize the state you can actually access, including open questions and gates.
Do not reconstruct missing evidence. Then continue from the Step's objective.
```
5. Verify its summary before continuing.

## When switching agents
Finish the current Stop condition, complete its handoff, select the next agent, provide the handoff/artifacts, and verify the new agent recognizes the baseline. The most important switch is Step 6 → Step 7 using the DT→BRD handoff.

## Where notes go
Use [`workshop-output/`](../workshop-output/README.md). Prototype self-test notes have a template. Final confidence goes to `workshop-output/WORKSHOP-CONFIDENCE.md`.

## If agent behavior differs
Do not chase exact filenames. Check content against the step's Stop condition and [Artifact Checklist](ARTIFACT-CHECKLIST.md), use the recovery prompt, and repair substantive gaps before advancing.

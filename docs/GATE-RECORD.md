# Gate Record Template

For every material unresolved dependency, record:
- **Gate ID**
- **Title**
- **Owner**
- **Status:** Open / In progress / Closed
- **Affected requirements/features**
- **Exit evidence:** what must be true or evidenced to close the gate
- **Next decision trigger:** event or evidence that causes reassessment
- **Notes / remaining uncertainty**

Avoid scheduled dates unless one is genuinely known and supplied.
